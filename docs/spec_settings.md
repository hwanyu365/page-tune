## 3. 요구사항

### 3.1 사용자 스토리

- `US#1` 사용자로서, 앱 버전과 라이선스, 개인정보 처리방침을 앱 안에서 확인하고 싶다 [요구사항] GH-55

### 3.2 기능 요구사항

- `FR#1` 메인 화면 툴바 오버플로 메뉴의 "설정" 을 누르면 설정 화면을 연다 [요구사항] GH-55
  - 오버플로 메뉴의 "오픈소스 라이선스" 항목은 없애고 설정 화면 안으로 옮긴다 (D#2).
  - 설정 화면의 뒤로가기(툴바 위로 버튼·시스템 뒤로가기)는 메인 화면으로 돌아간다.
- `FR#2` 설정 화면은 앱 정보, 오픈소스 라이선스, 개인정보 처리방침 세 항목을 순서대로 보인다 [요구사항] GH-55
  - 앱 정보: 앱 이름과 설치된 버전 이름. 버전은 실행 중인 패키지 정보에서 읽는다 → 빌드 설정을 바꾸지 않는다.
  - 오픈소스 라이선스: 누르면 `res/raw` 의 고지 원문을 보여준다 (`spec_tune_edit.md` NFR#4).
  - 개인정보 처리방침: 누르면 FR#3 으로 처리방침 주소를 연다.

  ```
  Given versionName 이 1.2.0 인 빌드를 설치했다
  When  설정 화면을 연다
  Then  앱 정보에 PageTune 과 1.2.0 이 보인다
  ```

- `FR#3` 처리방침 주소는 시스템 브라우저 등 다른 앱으로 연다 (`ACTION_VIEW` + `CATEGORY_BROWSABLE`). 열 앱이 없으면 열 수 있는 앱이 없다는 안내와 주소를 보인다 [요구사항] GH-55
  - 주소는 `spec_store.md` §4 게시 경로 `https://hwanyu365.github.io/page-tune/privacy` 다. 번역하지 않는 문자열 리소스 하나에 둔다.
  - 앱의 열람 화면에서 열지 않는다 → 열람 화면은 등록된 웹페이지 전용이다 (`spec_page_view.md` FR#7).

  ```
  Given 브라우저 앱이 설치돼 있다
  When  개인정보 처리방침을 누른다
  Then  브라우저에 처리방침 페이지가 열린다
  ```

### 3.3 비기능 요구사항

- `NFR#1` 화면 문자열은 문자열 리소스에 두고 영어·한국어를 갖춘다 (`spec_tune_edit.md` NFR#2) [요구사항] GH-55
- `NFR#2` 접근성·디자인은 `spec_tune_edit.md` NFR#3, `spec_design.md` 를 따른다 [요구사항] GH-55
- `NFR#3` 권한·의존성을 추가하지 않는다 → `androidx.preference` 를 쓰지 않는다 (D#1) [요구사항] GH-55
  - 설정 Activity 는 `exported="false"` 다 → 다른 앱이 직접 열 수 없다.
